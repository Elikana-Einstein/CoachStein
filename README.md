# Fieldnotes — Engineering Roadmap Planner

A responsive TypeScript + React planner for turning personal goals into roadmaps, tracks, phases, and actionable tasks. The app lives in [`frontend/`](frontend/README.md).

## Run locally

```sh
cd frontend
npm install
npm run dev
```

Roadmaps persist in browser local storage. Data stays in the current browser and is not synced across devices or users.
